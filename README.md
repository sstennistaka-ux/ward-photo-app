# ward-photo-app（病棟フォトアプリ）

環境ラウンドの記録用PWA。iPhone/iPadのホーム画面に追加して単独アプリのように使えます。
病棟選択 → チェック項目（◯×ー）入力 → 写真撮影 の手順で記録し、Excel（チェック結果）とPowerPoint（チェック結果＋写真を反映済み）をまとめて書き出せます。

## 使い方

1. ホーム画面上部で今回のテーマ（洗浄室／薬品保冷庫／ナースステーション内手洗いシンク／シンク周囲／廃棄物の管理／点滴準備台／リネン庫およびランドリーカート）を選択
2. 病棟ボタンをタップ → その病棟・テーマのチェック項目に◯／×／ーを入力
3. 「写真を撮る」で撮影（何枚でも連続撮影可能。ファイル名は自動で `病棟名.jpg` → `病棟名-02.jpg`... と連番になります）
4. 「病棟選択に戻る」で一覧に戻り、次の病棟へ（入力途中でも自由に行き来できます）
5. ギャラリー画面の「確認・修正」で、書き出し前にその日の全病棟の回答を見直し・修正できます
6. 「まとめて書き出す」をタップすると、その日のデータが1つのZIPにまとまります
   - `環境ラウンドMMDD/`（写真フォルダ）
   - `環境ラウンドMMDD.xlsx`（チェック結果。テーマごとにシートを分けて出力）
   - `環境ラウンドMMDD(テーマ名).pptx`（チェック結果＋写真を反映済みのPowerPoint、テーマごとに1ファイル）
7. 共有シートで **AirDrop** を選んでMacに送信
8. Mac側でZIPをダブルクリックすると `環境ラウンドMMDD` フォルダ等が展開されます

## PowerPointの写真配置について

写真は変形（引き伸ばし）せず、縦横比を保ったまま枠の中に収めます（枠と縦横比が異なる場合は余白ができます／トリミングはしません）。1病棟の写真は最大3枚まで反映されます（4枚目以降は写真フォルダには入りますが、PowerPointには反映されません）。

チェック項目に×が1つもなく、かつ全項目が「ー」（未実施）ではない病棟には、自動で「Excellent!」のリボンが付きます。全項目が「ー」の病棟（今回未実施）にはバッジは付きません。

## ファイル名のルール(マクロ側と対応)

- 病棟ごとに1枚目 = メイン写真 → 拡張子以外は病棟名のみ(例: `5N.jpg`)
- 2枚目以降 = 連番(例: `5N-02.jpg`, `5N-03.jpg`)
- 連番は「日付＋病棟」ごとにリセットされるため、日をまたいでも1枚目は必ずメイン写真として扱われます
- 病棟名はファイル名内で単語単位一致するため、`ICU` の写真が `NICU` と誤認されることはありません

## 技術メモ

- 写真本体・チェック結果はいずれも IndexedDB に保存(旧版のlocalStorageは容量が小さく、8〜9枚目付近で保存に失敗する不具合があったため移行)
- ZIP生成には [JSZip](https://stuk.github.io/jszip/)、Excel生成には [SheetJS(xlsx)](https://sheetjs.com/)、PowerPoint生成には [PptxGenJS](https://gitbrent.github.io/PptxGenJS/) を使用（いずれもオフラインで動作するようアプリ内に同梱）
- 従来の `環境ラウンド.xlsm` のマクロは使わなくても運用できます（残しておいても支障はありません）。`環境ラウンド元データ.pptx` への追記は行わず、書き出しのたびに新しいPowerPointファイルが作られる方式です
- `service-worker.js` によりオフラインでもアプリ起動・撮影が可能(Wi-Fiが弱い病棟内での利用を想定)
- アプリ本体を更新した際は `service-worker.js` 内の `CACHE_NAME` を更新してください(例: `v2` → `v3`)。更新しないと古いキャッシュが使われ続けます
