# ward-photo-app（病棟フォトアプリ）

環境ラウンドの写真撮影用PWA。iPhone/iPadのホーム画面に追加して単独アプリのように使えます。

## 使い方

1. 病棟ボタンをタップしてカメラを起動 → 撮影(ファイル名は自動で `病棟名.jpg` → `病棟名-02.jpg`... と連番になります)
2. ギャラリー画面で「まとめて書き出す」をタップすると、その日の写真がすべて `環境ラウンドMMDD.zip` として1つにまとまります
3. 共有シートで **AirDrop** を選んでMacに送信
4. Mac側でZIPをダブルクリックすると `環境ラウンドMMDD` フォルダが展開されます
5. `環境ラウンド` フォルダ直下(`環境ラウンド.xlsm` と同じ場所)にそのフォルダを置けば、Excelマクロからそのまま参照できます

## ファイル名のルール(マクロ側と対応)

- 病棟ごとに1枚目 = メイン写真 → 拡張子以外は病棟名のみ(例: `5N.jpg`)
- 2枚目以降 = 連番(例: `5N-02.jpg`, `5N-03.jpg`)
- 連番は「日付＋病棟」ごとにリセットされるため、日をまたいでも1枚目は必ずメイン写真として扱われます
- 病棟名はファイル名内で単語単位一致するため、`ICU` の写真が `NICU` と誤認されることはありません

## 技術メモ

- 写真本体は IndexedDB に保存(旧版のlocalStorageは容量が小さく、8〜9枚目付近で保存に失敗する不具合があったため移行)
- ZIP生成には [JSZip](https://stuk.github.io/jszip/)(`jszip.min.js` に同梱、オフラインでも動作)
- `service-worker.js` によりオフラインでもアプリ起動・撮影が可能(Wi-Fiが弱い病棟内での利用を想定)
- アプリ本体を更新した際は `service-worker.js` 内の `CACHE_NAME` を更新してください(例: `v1` → `v2`)。更新しないと古いキャッシュが使われ続けます
